Como adicionar um servidor ao cluster

Baixe apenas um arquivo Python no servidor novo. O instalador cria o ambiente virtual se faltar, prepara o pip, instala as dependências, baixa o worker oficial e inicia tudo automaticamente. Requer Python 3.10+ e internet.

curl -L https://raw.githubusercontent.com/daniblockss/Bot-advanced/main/add_cluster_server.py -o add_cluster_server.py
python3 add_cluster_server.py

Execute esses dois comandos no terminal da máquina que você quer adicionar ao cluster. Na primeira execução, informe um ID único para esse servidor e as credenciais Firebase do worker. O instalador baixa bothub_firebase_worker.py por conta própria; você não precisa baixá-lo manualmente.

1. Se o servidor não tiver Python ou venv
O instalador precisa de Python 3.10+ para começar. Em Debian/Ubuntu, se o próprio módulo venv estiver ausente, ele mostrará o comando para instalar python3-venv e python3-pip. Depois, execute o instalador novamente.
2. Criar uma conta Firebase para o worker
No Firebase Console do projeto BotHub, abra Authentication → Users e crie uma conta de e-mail e senha para este dispositivo. Use uma conta separada por worker; não compartilhe a senha de administrador.
3. Autorizar o worker
Depois da primeira execução, encontre o UID dessa conta em Authentication → Users. Em Realtime Database → Dados, configure workerUids/ID_DO_DISPOSITIVO com o UID da conta como valor de texto. Use exatamente o ID digitado no terminal. Mantenha as regras privadas.
4. Confirmar no painel
Deixe o worker rodando e aguarde cerca de 15–30 segundos. A máquina deverá aparecer em Dispositivos / workers. Para iniciar automaticamente após reiniciar, configure o instalador/worker como serviço do sistema.

Se o dispositivo não aparecer, confira o terminal, internet, credenciais Firebase e o caminho workerUids. Não use o mesmo ID em duas máquinas.
