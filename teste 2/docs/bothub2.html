Como adicionar um servidor ao cluster

        
O único ponto de entrada é start.py. Ele baixa/verifica o instalador e o worker, registra os detalhes em start.log e transfere o próprio processo ao instalador. Requer Python 3.10+ e internet.

        
mkdir -p "teste 2" && cd "teste 2"
curl -fL https://raw.githubusercontent.com/daniblockss/Bot-advanced/teste-2/teste%202/start.py -o start.py
python3 start.py

        
Passos complementares:

        
1. Se o servidor não tiver Python ou venv
O instalador precisa de Python 3.10+ para começar. Em Debian/Ubuntu, instale python3-venv e python3-pip.

        
2. Criar uma conta Firebase para o worker
No Firebase Console, abra Authentication → Users e crie uma conta de e-mail e senha para este dispositivo.

        
3. Autorizar o worker
Em Realtime Database → Dados, configure workerUids/ID_DO_DISPOSITIVO com o UID da conta como valor de texto.

        
4. Confirmar no painel
Deixe o worker rodando e aguarde 15–30 segundos para aparecer na aba de Workers.
